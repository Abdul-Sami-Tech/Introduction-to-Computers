## Introduction to Computers

A computer is a machine which takes data and gives information after processing it. Computers are used for many different things in our daily life.

We use computers in schools, offices, hospitals, banks, businesses and for entertainment.

Input means giving data to the computer.

Processing means the computer works on the data.

Output means getting the result.

Storage means saving the data.

The purpose of this project is to learn about computers and also learn some basic use of Git and GitHub.

## Types of Computers

There are different types of computers. They are used for different purposes and some are more powerful than others.

Supercomputers are very powerful computers which are used for difficult calculations and scientific work.

Mainframe computers are used for large amount of data and can be used by many people at one time.

Minicomputers are smaller computers which were used for different work in organizations.

Microcomputers are mostly used by individual people. Laptops and desktop computers are examples.

Some common types are:

- Supercomputer
- Mainframe computer
- Minicomputer
- Microcomputer

| Type | Use |
|--|--|
| Supercomputer | Difficult calculations |
| Mainframe | Large data |
| Minicomputer | Organization work |
| Microcomputer | Personal use |
