## Introduction to Computers

A computer is an electronic machine which is used to take data, process it and give information. It can also save the data for later use. Computers are used almost everywhere nowadays.

We use computers in education, offices, businesses, hospitals, banks, communication and also for entertainment.

### Basic Functions of a Computer

Input means giving data to the computer.

Processing means the computer works on the given data.

Output means getting the result from the computer.

Storage means saving data in the computer.
